# Android To-Do List – Bitrise CI/CD Lab

A simple Android To-Do List application developed using **Kotlin**, designed for a hands-on workshop on **Continuous Integration and Continuous Delivery (CI/CD)** and **DevSecOps** using Bitrise.

## About the Application

This application allows users to manage their daily tasks through a simple interface.

### Features
- Add new tasks
- View existing tasks
- Mark tasks as completed
- Delete tasks
- Store tasks locally

## Getting Started

### 1. Fork This Repository

Click __Fork__ at the top-right corner of this GitHub repository to create your own copy.

### 2. Set Up Bitrise

1. Visit [Bitrise](https://bitrise.io) and create an account.
2. Connect your GitHub account using the [Bitrise GitHub App](https://github.com/apps/bitrise).
3. Import your forked repository into Bitrise.
4. Open the Bitrise Workflow Editor.
